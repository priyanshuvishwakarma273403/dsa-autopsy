# Examples

This directory contains standalone examples demonstrating how to use the `dsa-autopsy` package.

## Running the Basic Autopsy Example

The script `run_basic_autopsy.py` demonstrates how to instantiate the logging framework, configure settings, wire up dependency-injected engines, and run a mockup debugging session.

### Execution

To run the example, execute it using Python from the root of the repository:

```bash
python examples/run_basic_autopsy.py
```

Or using `uv` (recommended):

```bash
uv run examples/run_basic_autopsy.py
```
