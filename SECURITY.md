# Security Policy

## Supported Versions

Only the latest release of `dsa-autopsy` is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of `dsa-autopsy` and the **DSA Collective** ecosystem seriously. If you find any vulnerability, please report it privately:

- **Do not** open a public issue.
- Email your report to **security@dsacollective.org**.
- Include steps to reproduce the issue, details of the potential impact, and any suggested mitigations.

We will acknowledge receipt within 48 hours and work with you to coordinate a patch and release before public disclosure.
